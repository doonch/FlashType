# FlashType
Language-learning tools that help you memorize vocabulary.

https://doonch.github.io/FlashType

# Features
* Learn with your fingers: you *must* type in the correct answer in order to move to the next question.
* Speech: the questions and answers are read out loud for you by the browser.
* Passive mode: requires no typing, sit back and listen to an endless loop of question-answer pairs.
* AI sentence generator: using only vocabulary you want to practice, generate complete sentences with AI. Supports Cantonese.
